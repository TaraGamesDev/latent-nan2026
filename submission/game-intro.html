CADENCE

레벨을 만들지 않습니다. 매 순간을 설계합니다.

장르 화살표 퍼즐 · 무한 모드 플랫폼 웹 (모바일·데스크톱) 참가 개인 문서 게임 소개 및 설명

7×7 격자 위의 화살표를 눌러 판 밖으로 내보내는 퍼즐입니다. 규칙은 5초면 익힐 수 있지만, 화살표가 도중에 막히면 그 자리에 멈춰 다른 화살표들의 길을 바꿉니다. 그래서 무엇을 누르느냐가 아니라 어떤 순서로 누르느냐가 게임의 전부입니다.

그리고 플레이어가 화면을 누를 때마다, AI 디렉터가 그 한 번의 탭으로 플레이어의 실력을 다시 추정하고 다음 순간에 놓일 화살표를 설계합니다. 게임 안의 AI 패널에서 그 판단 과정을 그대로 볼 수 있습니다.

게임 방법

목표

화살표를 판 밖으로 내보내 점수를 얻습니다. 보드가 더 이상 움직일 수 없게 되기 전까지 최대한 오래, 최대한 많이 내보내는 것이 목표입니다. 클리어 조건이 있는 스테이지가 아니라, 압력이 계속 오르는 무한 모드입니다.

조작

화살표를 한 번 누르는 것이 전부입니다. 모바일에서는 탭, 데스크톱에서는 클릭. 드래그·길게 누르기·제스처는 없습니다.

규칙

상황결과
탈출 누른 화살표가 가리키는 방향으로 미끄러져 판 가장자리까지 도달하면 판 밖으로 나가고 득점합니다.
정지 가는 길에 다른 화살표가 있으면 그 앞 칸에 멈춰 섭니다. 득점은 없지만 보드가 재배치되어 다른 화살표들의 길이 열리거나 막힙니다.
잼 바로 앞 칸이 이미 막혀 있어 한 칸도 움직일 수 없으면 아무 일도 일어나지 않고 흔들립니다. 콤보가 끊기고 그 탭은 낭비됩니다.

“정지”가 이 게임의 핵심입니다. 만약 화살표가 길이 뚫려 있을 때 그냥 사라지기만 한다면, 타일 제거는 길을 열기만 하므로 어떤 순서로 눌러도 결과가 같아집니다. 막힌 화살표가 새로운 자리에 남기 때문에 A를 움직이면 B의 길이 막히거나 열리고, 비로소 순서가 의미를 갖습니다.

점수

  • 탈출 1회 = 10 + 2 × 이동거리 + 5 × 현재 콤보
  • 탈출할 때마다 콤보 +1. 멀리서 날아온 화살표일수록 점수가 높습니다.
  • 득점 없이 위치만 바꾼 경우 콤보 −1 (0 미만으로는 내려가지 않음)
  • 잼이 나면 콤보 0으로 초기화

위치를 바꾸는 수는 필요악이라 콤보를 완전히 없애지는 않고 깎기만 합니다. 콤보를 끊는 것은 오직 잼입니다. 여기서 실제 긴장이 생깁니다 — 지금 무리해서 탈출을 만들 것인가, 콤보를 조금 잃고 판을 정리할 것인가.

종료 조건

게임이 끝나는 방식은 두 가지이며, 둘 다 플레이어 자신의 선택이 만든 결과입니다.

  • 데드락 — 보드에 남은 모든 화살표가 한 칸도 움직일 수 없는 상태
  • 보드 초과 — 새 화살표가 나와야 하는데 빈 칸이 하나도 없는 상태

목숨이나 하트는 없습니다. 잼은 목숨을 깎는 대신 턴을 낭비하게 만듭니다 — 그리고 잼이 난 탭에도 디렉터는 화살표를 스폰합니다. 그래서 잼은 보드가 여유로울 때는 거의 공짜지만 후반에는 치명적입니다. 실제 무게와 정확히 일치합니다.

화면 구성

AI 디렉터 패널

우상단 “AI 패널” 버튼 또는 D 키로 열립니다. 이 게임의 AI가 무엇을 하고 있는지 숨기지 않고 전부 보여주는 화면입니다.

  • 시스템이 지금 당신을 어떻게 추정하고 있는가 — 숙련도 θ와 계획성·효율·템포
  • 숙련도 · 목표 난이도 · 실제 난이도가 겹쳐 그려지는 플로우 채널 그래프
  • 이번 스폰을 그렇게 결정한 이유 (한국어 문장)
  • 검토된 후보 배치들과 채택되지 않은 대안들, 각각의 점수
  • 불변식 검증 결과 — “스폰 직후 최소 1수 이동 가능”이 실제로 충족되었는지
  • 솔버가 증명한 탈출 체인이 보드 위에 번호로 직접 표시됩니다

기술적 세부 사항은 별도 제출물 ④ AI 활용 기술 문서에 정리했습니다.

실행 방법

플레이 (심사자용)

위 플레이 링크를 클릭하면 끝입니다. 설치 과정이 없습니다. 모바일 브라우저와 데스크톱 브라우저 모두에서 동작하며, 세로 화면을 기준으로 설계했습니다.

소스에서 직접 빌드

git clone https://github.com/TaraGamesDev/cadence-nan2026.git
cd cadence-nan2026
npm install

npm run dev     # 개발 서버 — http://localhost:5173
npm run build   # docs/ 로 정적 빌드 (GitHub Pages가 서빙하는 산출물)
npm run bench   # 헤드리스 엔진 검증 (규칙·솔버·디렉터)
npm run tune    # 오프라인 디렉터 정책 튜닝

Node.js 20 이상이면 동작합니다 (개발 환경은 Node 22.14). npm run bench는 심사자가 게임을 검증하는 데도 쓸 수 있습니다 — 봇 페르소나로 전체 게임을 돌려 불변식 유지·런 종료·숙련도 추정의 정렬을 단언합니다.

제작 범위

개인 참가입니다. 기획·게임 디자인·엔진·AI 시스템·UI·문서 전부를 직접 작성했으며, 개발 과정에서 Anthropic Claude를 코딩 협업 도구로 사용했습니다. 사용 내역은 ④ AI 활용 기술 문서에 빠짐없이 기재했습니다.

외부 에셋은 사용하지 않았습니다. 이미지·사운드·폰트 파일이 저장소에 하나도 없으며, 화면의 모든 그래픽은 코드로 그려집니다. 런타임 의존성도 0개입니다.
